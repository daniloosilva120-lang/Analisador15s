ANALISADOR15s - PACOTE PORTATIL

Necessário:
- JDK 26: https://jdk.java.net/26/
- Google Chrome: https://www.google.com/chrome/
- IntelliJ IDEA é opcional: https://www.jetbrains.com/idea/download/

COMO USAR
1. Instale JDK 26 e Chrome.
2. Execute INICIAR_CHROME.bat.
3. Faça login MANUALMENTE na plataforma e abra GBP/USD OTC.
4. Execute RODAR_ANALISADOR.bat.

Não coloque senha, cookie ou token no código.

O programa atual:
- lê as cotações pelo Chrome local;
- monta candles de 15 segundos;
- analisa os candles;
- não executa ordens;
- tenta reconectar se a conexão cair.

A porcentagem de "confiança" é um score heurístico, não uma probabilidade garantida.
